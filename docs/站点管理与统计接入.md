# 站点管理与统计接入（2026-10-26）

## 部署

1. 先备份当前应用数据库。已有站长分析功能的数据库应已执行 `sql/10_site_analysis_20261025.sql`；新库先执行该文件。
2. 在同一个应用 MySQL 库执行一次 `sql/11_site_management_20261026.sql`。文件支持重复执行，只新增接入配置表与访问事件表，不删除既有站点、报告、积分或订单。
3. 同步本轮完整代码后继续使用 `bash upgrade.sh` 构建与启动。升级脚本不自动执行 SQL；不需要再次安装视频引擎、修改 OSS 密钥或新增 npm 依赖。

固定域名 / 短脚本更新不新增 SQL。请将本轮代码部署到 `https://www.yxstar.shop`，以提供 `/s/` 接口；该线上环境中须存在对应站点配置。本地使用独立数据库新增站点，不会仅因生成了线上地址就自动把站点同步到线上。

新服务器仍使用原 `migration_upgrade.sh` 准备业务依赖。迁移步骤 `20-site-analysis.sh` 仅检查站长分析依赖并提示 SQL 顺序，不连接或初始化业务数据库。

## 宇星脉通自身站点已接入代码

用户提供的 `https://www.yxstar.shop/s/RDYfVdtkRd-iXLHGxvrdEA` 已加入 `app/layout.tsx` 的公共 `<head>`，使用异步加载，所有页面共用，不必在首页、商品、工具或个人中心逐页重复粘贴。生产HTML中可直接读取到真实script元素，供服务端验证。

该接入额外设置 `data-exclude-path="/admin"`，跳过管理端及其子页面的统计；页面不移除脚本资源，但这些路径不会产生访问事件。前台与管理端之间的SPA路径变化同样按此范围处理。脚本还会校验配置站点域名，localhost或其他域名不发送访问事件，正常兼容裸域 / www别名。原有服务端来源校验保留。

部署当前代码后，登录线上站点管理，在这段脚本所属站点卡片点击“已安装，开始验证”。验证通过后刷新商城首页，再刷新统计查看最近访问与来源。代码安装不等于数据库已完成验证，本轮没有修改真实站点的验证状态；如果该站点只存在于独立本地库，仍需按迁移方式将对应配置放入线上库。无需新增SQL、密钥或手工修改Nginx。

## 用户操作

1. 登录平台进入站长分析工具。左侧第一项、默认页面是“站点管理”。新脚本统一指向 `https://www.yxstar.shop`，即使从 localhost 打开页面也不改变这个来源；正式接入应在对应线上环境中配置站点。
2. 输入自己的公开站点域名并添加。添加只保存配置，不创建分析任务或扣费。每个账号最多保留 100 个未删除站点。
3. 已有脚本站点的接入面板读取后默认展开，可直接复制；可手动收起 / 查看，刷新后恢复展开，不产生生成或验证请求。旧站点缺少脚本时点击本站卡片“生成脚本”补齐。已有脚本直接复用，重复点击、刷新和重新登录不更换站点 token，也不影响验证状态。将脚本加入目标网站公共页面的 HTML，建议放在 `<head>` 中；至少首页需要直接包含该脚本。纯客户端运行后才插入脚本、HTML 注释、`template`、`noscript` 或非 JavaScript 脚本块不能通过验证。
4. 若目标网站有 CSP，在 `script-src` 和 `connect-src` 允许 `https://www.yxstar.shop`；平台统计接口须由访客直接访问。不要把脚本域名手动改为 localhost、内网平台地址或 HTTP 来源。
5. 点击“已安装，开始验证”。本站卡片即时显示验证中，并在按钮下方给出通过 / 失败、具体原因及本次检查时间；成功后可进入综合看板，失败可以重试。验证有10秒请求间隔，过早重复请求显示“等待重试”和剩余秒数，不显示验证失败；倒计时结束后手动重试，不自动发送验证。前端单次等待最多25秒，超时 / 网络异常明确回执，缺失或错误回执不显示成功。平台服务器读取目标首页，确认脚本来源和本站固定标识完整匹配。收到访问上报本身不会取得站点验证状态。
6. 验证通过后，可以进入综合看板，选择站点并点击分析。选择只填入配置地址，不自动分析；不能通过手动改写地址、直接调用分析接口来跳过站点验证。

刷新页面时从服务器读取已保存的验证状态及最近通过时间；每次操作的回执在所属站点卡片内显示。临时网络错误不自动撤销既有验证资格，真正的状态变化仍以服务器返回为准。以上展示调整无需新增SQL，也不改变原验证权限或脚本标识。

客户面板说明简化为：点击生成脚本后永久固定不变；验证通过后用于绑定站点的数据统计与分析；删除统计脚本后将不再统计，历史分析数据依然保留。下面的技术说明供部署维护时查阅。

新脚本形式如下，实际值以站点管理为准；不要把占位标识安装到网站：

```html
<script async src="https://www.yxstar.shop/s/本站22位固定标识"></script>
```

22位标识由既有站点UUID完整编码得到，没有截取哈希或重新随机分配，不会因刷新、重复生成或同账号删除再添加而变化。内部已有64位token同样保留，原 `/api/site-tracker/64位token` 路由继续兼容；已经使用正确公网域名的旧脚本可继续使用。含 localhost 的旧代码应重新复制新版；切换长短格式不清空历史、不重复创建站点，两个地址的访问归入同一站点。

每个站点有永久固定的独立标识，不使用其他站点的脚本。裸域与其 `www` 别名可用于首页跳转、验证和访问来源匹配；其他子域名应单独配置。只有当前账号可以管理站点、读取统计和历史报告。未验证的历史站点需先生成脚本、安装并验证，原报告仍可直接查看。

## 删除与重新添加

- 删除前展示确认说明；确认后只记录 `deleted_at`，不物理删除任何历史报告、关键词、页面或访问事件。删除不退款，也不额外扣费。
- 删除后不再接受该站新分析或访问事件，原脚本暂停服务但标识保留；已经提交的分析任务继续完成，原报告和统计仍可读取。
- 重新添加同一账号的同一域名会复用站点编号、原 token 和历史，并重置验证状态。原脚本仍安装在站点时无需替换，重新验证后恢复统计。
- 重新添加后的近 30 天统计可包含该站保留下来的旧事件；待验证时明确标记为历史统计。

## 统计口径

- 安装并验证后开始累计，不回填安装前的访问。综合看板展示所打开报告对应站点的实时近 30 天访问统计，独立于该报告的历史采集时间；刷新记录可更新统计。
- 页面浏览量按成功接收且去重后的页面事件统计。访问次数按匿名会话统计；会话保存在 `sessionStorage`，30 分钟不活动后重建，同一标签页内沿用。不是跨设备独立访客人数，不能当作精确 UV。
- 来源占比按会话首次来源计算：直接访问、搜索引擎、邮件、外链、社交媒体与其他。使用有限的公开来源域名和 `utm_medium` 规则；无 referrer 的访问可能归入直接访问，结果不是广告平台官方归因。
- 普通页面加载及 SPA 路径变化会记录浏览；同一路径重复事件、重复加载同一脚本会去重。只改变查询参数或片段不新增浏览。没有 Cookie、登录态、原始 IP、完整来源路径、网址查询参数或片段入库；服务端保存路径、来源分类、匿名会话摘要和时间。
- 尊重浏览器 DNT / GPC；脚本被拦截、禁用 JavaScript、访客离线、未验证、浏览器拒绝请求或限流时不会产生访问记录。自动化 UA 会被过滤；这些统计不是防作弊或审计计费依据。
- **当前没有接入 IP 地区库，国家显示“未识别”**，不根据语言、时区或域名猜测国家。未接入、请求失败、零访问和已删除历史分别展示，不编造百分比或国家数据。
- 访问统计不提供搜索引擎收录总数、全网关键词搜索量或官方排名。收录面板继续显示未接入和人工核对入口。

## 数据与运行边界

- `site_analysis_integrations`：站点所属账号、唯一 token、验证 / 最近上报 / 删除时间。`site_analysis_visits`：事件幂等键、会话摘要、页面路径、来源分类、国家占位与时间。
- 事件写入采用事务，重新确认站点有效性，删除或未验证期间拒绝请求；不参与积分、会员或订单扣费。验证请求使用独立标记，删除再添加也不会被删除前尚未完成的验证请求错误恢复。
- 上报请求体最大 4096 字节，每进程每 token 每分钟最多 12000 次，限流窗口有数量边界。这是当前基础保护；多实例部署的全局配额、采集批处理和独立统计存储需按访问规模另行扩展。
- 没有定期物理清理或数据到期删除任务；“保留历史”不会因为删除站点而触发清理。随着事件累计，需要运维评估容量、备份与后续归档策略。
- 本轮仅完成代码与模拟数据验证，没有连接真实业务库或安装到真实站点；真实接入和页面视觉由部署后用户验收。
