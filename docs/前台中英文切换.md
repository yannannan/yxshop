# 前台中英文切换

前台顶部账户区旁提供“简体中文 / English”选择。默认中文，切换后刷新当前地址，路径、查询参数和锚点不变；编辑资料、地址等表单时应先保存。语言保存到本站 `yxshop_locale` Cookie，有效期一年，不需要登录、不修改账号或积分数据。

覆盖首页与频道、商品目录与详情、工具目录与操作页、积分充值、个人中心、地址、商城与技术服务订单、技术服务介绍及技术人员工作台。页面标题、输入提示、按钮、状态及主要错误提示使用同一词库。价格仍为人民币，服务时间仍按北京时间显示，套餐、分类和表单向接口提交的原值不变。

管理员明确要求管理端不提供英文：`/admin` 内固定使用中文语言上下文，不显示语言切换入口，也不会把用户在前台保存的英文偏好改回中文。后台权限仍由已有的签名会话和管理员权限校验决定。

本功能翻译界面文案与已知系统标签；用户昵称、视频标题、聊天、地址、商品与服务介绍等后台维护或用户填写的业务内容保留原文。不会调用外部翻译服务、改写数据库内容或转换人民币价格。印章中用户输入的文字及历史导出文件也保持原样。

## 代码入口

- `components/language-switcher.tsx`：切换及偏好保存。
- `components/language-provider.tsx`：React 语言上下文，按页面树隔离。
- `lib/i18n.ts`：两种语言校验、界面词条及动态提示翻译。
- `lib/i18n-en.ts`：英文词库；新增界面文案时同步补充。
- `lib/i18n-server.ts`：按当前请求读取 Cookie，渲染页面与元数据，不使用全局请求语言变量。
- `app/admin/layout.tsx`：后台固定中文。

## 发布与验收

无需 SQL、环境配置或新增依赖。同步完整代码后照常运行 `bash upgrade.sh`，视频依赖策略不变。

按项目约定，助手只做代码检查和直接生产处理器渲染，不启动浏览器或商城服务、不连接真实业务数据库。请本地验收：

1. 匿名首页切换 English，跳转工具、商品、积分及账户页后保持英文；刷新、重新打开页面后偏好保留。
2. 登录后查看个人资料、积分和订单；业务内容仍为原文，地址与工具表单提交值和收费规则不变。
3. 英文前台进入管理端，后台与共用账户菜单保持中文；返回前台仍为英文。
4. 切回中文，页面恢复中文；窄屏导航可横向滚动，语言入口和账户菜单可使用。

语言偏好 Cookie 被浏览器禁用时会回退为中文。中英文共用原路由和 canonical，没有额外创建多语言 URL 或独立英文业务资料。
