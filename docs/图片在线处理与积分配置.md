# 图片在线处理与积分配置

入口：`/tools/image-processor.html`，工具名称为“图片在线处理”。前台支持中文 / 英文，管理端保持中文。

## 第一版功能

- 左侧：去水印、图像拼接、图像压缩，以及待定入口。上方：变清晰、图片修复、抹除区域、抠图、文字替换。
- 去水印 / 抹除：手动框选小面积区域，以周围背景插值修补。图片修复可进行全图基础降噪，或框选局部修补。
- 变清晰为基础锐化，抠图为指定颜色、容差的边缘连通背景移除。文字替换为选区背景色覆盖并写入新文字。均为用户已确认的手动 / 基础算法，不包含自动对象识别、OCR、生成式修复或AI超分。
- 拼接支持横向、纵向、网格、顺序调整、间距、背景色；JPG支持质量参数，PNG无损，不承诺输出一定小于原文件。抠图强制透明PNG。
- 中间为原图 / 处理结果对照；右侧结果提供文件大小、处理尺寸、实际扣分与下载。最近5个成功结果可重新打开，刷新带有`result`参数的链接也能恢复；原图不保存。

## 积分与权限

用户可先上传、查看原图和调参；生成需要登录。服务器完成处理后，在同一MySQL事务中复核当前工具 / 模块价格、套餐、账户、扣分并保存成品；失败回滚，不交付未结算成品。

同一任务编号 + 图片像素 + 参数指纹可重试恢复，不重复扣分。前端断线后保留任务编号，即使剩余积分已不足，也可重试恢复已成功成品。下载只校验当前账号归属，不扣积分。既有有效会员 / 套餐先于积分使用；按次套餐仅成功时扣一次。价格变化拒绝旧报价后重试，不按新的更高价格静默扣分。

管理端 → 工具服务 → 每一行的“积分配置”：设置工具默认积分及免费 / 按积分 / 待确认，原付费工具可保留套餐。图片工具8个功能可分别设置模块积分，留空继承默认值。管理员须有工具管理权限，普通用户无权读写配置。原“编辑 / 收款配置”仍可维护完整套餐及收款码。外部网页工具继续需要原服务端成功回调才能扣分。

## 部署

1. 在当前应用MySQL库备份后执行 [12号增量SQL](../sql/12_image_processing_20261102.sql)。前置为02 / 03 / 06 / 07号，已执行的不必重复。12号建模块积分、图片成品两表，并补入新工具；重复执行不覆盖已维护的价格、状态或旧业务数据。
2. 同步完整代码后按原方式运行`bash upgrade.sh`构建发布。新工具默认上架、每成功任务10积分，发布前可在管理端调整。原upgrade.sh不变。
3. 新服务器`migration_upgrade.sh`会自动执行30号图片依赖检查并提示12号SQL；不自动写数据库。不新增系统库、付费服务、密钥、网络模型下载或NPM包。复用jpeg-js、Resvg WASM、项目本地字体，兼容既有Windows / Linux部署方式。

浏览器将每张大图适配至200万像素以内，再上传RGBA像素；页面明确展示实际处理尺寸。单张原文件20MB，最多8张，总输入600万像素，单请求25MB，结果不超过600万像素 / 8MB。成品以Base64保存到MySQL MEDIUMTEXT，需允许相应的数据库请求大小；原始文件名和EXIF不上传或入库。没有使用视频OSS配置。

## 验收

代码检查在隔离模拟数据库和临时进程进行，不启动商城服务、不使用浏览器或真实业务数据库、不执行SQL。真实数据迁移、页面视觉、鼠标 / 触屏框选和实际扣分由用户在本地或服务器验收。测试覆盖真实图像编码及像素处理、失败回滚、并发最后积分、重试幂等、会员 / 次数优先、调价、账号隔离、管理权限与双语生产页面。
