# 前台统一视觉主题（2026-11-19）

以AI智能获客宣传页为视觉基准：雾白/冰蓝页面背景、浅蓝至淡青的渐变层次、深蓝正文和品牌蓝操作按钮。保持既有内容、分页和业务流程，平台标志、商品图片、二维码和用户素材不做滤镜或重着色。

## 统一范围

- 共用导航、账户菜单、登录弹窗、搜索、分类切换、分页、全局手机扫码及客服入口。
- 首页两个Banner、频道入口、工具/商品卡片、目录、商品详情、下单支付和订单列表。
- 个人中心、资料、积分、充值套餐、地址管理。
- 上门技术服务、技术人员详情、预约/服务订单、在线咨询及技术人员工作台。
- 文件签署、签名/印章/手印制作、图片处理、站长分析、视频提取工作区及工具介绍页。
- 磁盘管家宣传页和AI智能获客工作台；AI获客宣传页继续作为参考，微调共用按钮及小字可读性。

## 视觉规则

- 品牌蓝 `#2468e3`，悬停 `#1856c2`，正文 `#183353`，辅助文字 `#586f8a`，描边 `#d9e5f3`。
- 白色卡片配轻描边和柔和阴影；主背景与功能介绍使用浅蓝/淡青渐变，侧栏统一深海军蓝以区分导航和内容区域。
- 主按钮为蓝底白字；辅助按钮为白底蓝字；统一悬停、选中、禁用与键盘焦点。主要操作手机触控高度至少44px，保留既有响应式网格和工具滚动/缩放规则。
- 图片工具的顶栏/页脚由暗转亮时同步覆盖局部文字变量，防止原浅色字落在浅背景上；AI工作台的表格、筛选、字段和提示同样改为浅色体系。
- 继续用红/橙/绿表达错误、警告、成功；错误字段保留红色边框，不把签署错误说明改成普通辅助文字。支付方式的品牌色、评分星级和业务状态保持原语义。
- 不修改SVG图形填色、画布像素、素材透明度、字体参数、二维码图案、签署定位或原图。

## 维护方式

主题集中在 `app/public-theme.css`，由根布局在原模块样式之后导入。规则限定在 `body:not(:has([data-admin-ui]))` 下，原模块保留排版与业务状态定义。

管理布局对登录与登录后页面均输出 `data-admin-ui` 标记，前台主题不会在管理端生效。这样无需在页面切换后用JavaScript更换主题，服务端初始HTML即可决定隔离；没有新增导航、第三方字体或外部资源。

新增前台模块应优先复用 `--ui-primary`、`--ui-ink`、`--ui-muted`、`--ui-line`、`--ui-soft` 和 `--ui-hero`，主/次按钮按语义补充到主题的相应分组，避免重新引入独立橙色/棕色操作体系。
