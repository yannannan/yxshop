# 印章制作与工具会员配置

2026-10-23。本轮实现 `/tools/stamp-maker.html` 的实际印章制作功能。

## 升级步骤

1. 在项目目录执行 `pnpm install --frozen-lockfile`，安装渲染依赖 `@resvg/resvg-wasm` 及 JPG 编码依赖 `jpeg-js`。项目同时更新了 npm 锁文件；无需额外安装本机图形库。
2. 在应用 `.env.mysql` 实际连接的 MySQL 数据库执行整个 `sql/06_stamp_maker_20261023134112.sql`。前置为既有商城及 02 / 03 工具套餐迁移。06 增加订单套餐标识 / 分类名称快照、成品表，并只为印章工具补齐空入口；不修改收费方式、价格、上架状态或旧订单权益。脚本可重复执行，助手未执行。
3. 保留项目 `assets/fonts/` 目录；字体已随代码提供，不需要在 Linux 上另外安装中文字体或本机图形依赖。字体只在服务端读取，不随页面传到浏览器。
4. 执行 `pnpm build` 并使用原项目脚本重启；本地开发环境安装依赖及完成 SQL 后，由用户运行调试。
5. 在管理端“工具服务”编辑“印章在线制作”，确认页面标识为 `stamp-maker`、状态已启用。选择“免费”即可直接制作；选择“收费”后配置本工具的会员 / 按次套餐和收款码。保留“待确认”时只开放预览，不开放制作。

06 必须在使用新版订单创建接口前执行，因为订单需要保存新增的套餐快照。上一轮首页排序若尚未执行 05，仍需按其原说明完成。

## 页面布局及功能

- 顶部沿用商城导航，含商城、上门技术服务、人才入驻、我的订单和返回首页；面包屑可返回工具目录。
- 桌面顶部为横向标题区域：“印章在线制作”、简单三步说明及功能标识同排。下方三栏顶部对齐：左侧选择样式及填写内容，中间预览及成品，右侧颜色与排版、套餐及最近制作。
- “导出下载设置”横向放在预览正下方，当前权益及刷新按钮并入标题横条；正文尺寸、格式、背景和制作按钮横排。窄屏根据可用宽度换行，手机为单列。右侧颜色排版桌面单列，平板整行展示时双列，手机单列。
- 四种样式：圆形、椭圆形、方形及个人姓名章。
- 名称、辅助文字、底部编号、颜色、边框、内边框、旋转可调；四种样式均可选择宋体、黑体或霞鹜文楷，印章名称、辅助文字及编号统一使用所选字体。姓名章为二至四字；方章自动按字数排版。
- 圆形 / 椭圆形另有字号、文字弧度、文字距边框及中心图案。间距范围 0～100，默认 12 保持原来的排版；数值越大，名称沿原弧度向内移动，辅助文字、编号及边框位置保持固定。该数值为相对排版量，非导出图片的像素距离；实际留白也受字体、字号和边框粗细影响。
- 字体及间距调整均自动更新预览，并用于最终高清成品。切换印章样式保留这两项选择，点击“重置”恢复宋体及默认间距。旧客户端缺少这两项参数时沿用默认值；服务端校验字体白名单及间距范围。
- 预览由服务端输出 420 像素、带水印的 PNG；输入有效参数后自动更新，不扣次。
- 制作输出无预览水印的 PNG、JPG 或 SVG，尺寸从小到大为 256 / 512 / 768 / 1024 / 1280 / 1600 / 2048 / 2560 / 3072 / 4096，默认 1600。PNG 和 SVG 可选透明或白底，JPG 强制白底并禁用透明背景选择；预览仍为固定 420 像素水印 PNG。
- SVG 输出已转轮廓的中文字形，不依赖接收方安装字体；所选尺寸决定画布大小。JPG 使用服务端像素编码为实际 JPEG 文件，文件扩展名为 `.jpg`。页面和接口会按成品实际格式提供 MIME 与下载名称，不通过改扩展名伪装格式。
- 成品文件由服务端生成，不接受浏览器传入最终图像、价格或扣次结果。付费记录继续保存原始文件 base64，读取时根据文件头恢复格式；原有 PNG 记录和下载地址继续兼容，无需新增数据库字段。
- 付费成品保存在数据库，“最近制作”展示本账号、本工具的最近 5 张，可重新打开下载。免费成品在本次页面中下载，不保存到付费历史中。

## 每个工具独立的会员及价格

用户已确认采用“每个服务工具独立会员或按次”的模式，印章会员不通用到其他工具。

在每个工具的“收费与收款”中配置：

- 会员 / 套餐分类名称，例如基础会员、专业会员、单次制作；名称由管理员定义，不预设实际价格。
- 周期：按次、包天、包周、包月、包年、一次性长期。
- 对应售价。同一工具可同时配置“基础会员 + 包月”和“专业会员 + 包月”，各自定价。同一分类名称 + 周期不能重复，每个工具最多 24 个套餐。

分类是本工具的套餐名称与定价分类；当前各分类均提供该工具制作权益，未假设不同等级的功能范围、分辨率特权或全站通用权益。按次套餐每笔购买提供 1 次成功处理，时长会员在有效期内制作不扣次数。

套餐有独立标识，购买时按服务端配置定价；订单保存成交价格、分类名称、套餐标识和计费周期，后续改名、改价不追溯改变已购权益。旧的仅含“周期 + 价格”的工具套餐及历史长期权益保持兼容。

支付二维码继续按“工具 + 套餐金额”配置，同金额套餐共用收款码；支付仍走既有商城收银台和后台人工核验。支付核验后返回工具页点击“刷新”读取权益。包月 / 包年仍按北京时间自然月 / 年从首次支付核验起生效，不自动续费。

## 制作、扣次和重试

1. 浏览页面、修改参数、预览、读取权益均不扣次。
2. 点击制作，先校验当前真实会话和本工具订单权益。
3. 服务端成功渲染图片后，在同一 MySQL 事务中复核账号、工具状态及订单有效性，扣减按次余额、记录成功事件并保存成品。任一步失败整体回滚。
4. 有效时长 / 长期权益优先于按次权益，避免包月生效期间扣次数。
5. 同一账号并发使用最后一次权益时，只允许一个不同任务成功；同一任务重复请求只返回已有成品。任务绑定账号、工具及参数指纹，修改参数或借用他人任务编号会被拒绝。
6. 网络中断后可以“重试本次制作”，保留相同任务编号；即使最后一次已被该任务消耗，也可恢复成品而不重复扣次。刷新页面不会自动发起制作；付费历史可从最近制作找回。
7. 下载已有成品不要求再次购买当前套餐，且不扣次；仍必须是已登录的成品所属账号，工具须处于启用状态。

新接口：`GET/POST /api/tools/stamp-maker`（权益、制作及成品读取）、`POST /api/tools/stamp-maker/preview`（受限尺寸预览）。原工具独立页面地址、分类排序及目录分页不变。

## 2026-10-23 本地预览故障修复

“预览暂不可用”曾在用户本地返回 HTTP 503。复现原因为开发热更新重新执行渲染模块，而外部 `@resvg/resvg-wasm` 实例仍已初始化；再次执行 `initWasm()` 会抛出 `Already initialized`。

初始化 Promise 现按 Wasm 包的函数实例保存在进程共享 WeakMap 中，跨热更新复用；修复前已初始化的进程会先验证渲染实例可用再继续。真正的初始化失败仍抛出并允许后续请求重试。字体读取和成功扣次规则不变。

修复前现有本地接口返回 503，修复后三种字体均返回 200 / image/png；没有发起成品制作、收费或扣次。界面发生预览错误时新增“重新预览”，仅重发当前参数的免费预览请求，无需改动文字。

## 2026-10-23 导出格式及下载设置

本轮增加 `jpeg-js`，更新生产环境时先执行 `pnpm install --frozen-lockfile`，再构建和重启；本地依赖已安装。无需新增 SQL，也未修改业务数据库。

格式和尺寸属于制作参数。成功制作一个新参数组合时遵循原按次 / 会员规则；打开预览和重复下载已完成的同一成品不扣次。PNG 默认参数保留上一版本的服务端任务指纹，升级前已成功的请求仍可原编号重试。
