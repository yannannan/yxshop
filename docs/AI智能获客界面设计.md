# AI智能获客界面预览

2026-11-15。本轮只落地页面与演示交互，不接入真实采集、模型、客户数据或积分扣费。

## 访问入口

- 顶部“AI智能获客”和工具目录新增卡片都进入 `/ai-leads`。
- 宣传页的“开始我的获客”进入 `/ai-leads/workspace`。
- `/tools/ai-leads.html` 永久重定向到同一个宣传页。
- 两个页面共用商城的 StorefrontHeader、语言与账户组件，账号、管理员入口和积分信息沿用现有功能。全局手机访问二维码也继续展示。

## 当前宣传页（纵向功能叙事版）

按用户最新要求，移除宣传页内部额外的产品导航，只保留商城共用顶部导航。页面使用雾白、冰蓝与品牌蓝，按以下顺序纵向展示：

1. 首屏说明AI获客目标，明确“开始我的获客”入口，展示三张功能场景轮播。
2. 目标市场与平台：国内、海外与代理商场景；按全部/国内/海外筛选规划中的平台。
3. 关键词与数据精度：产品/行业词、营销内容、每次数量与信息字段。
4. 客户画像与线索管理：客户背景、分类状态、检索和跟进记录。
5. 四步使用路径、简短体验说明与末屏开始入口。

原先办公室、港口、城市等泛化摄影已从页面及发布素材中移除。使用内置image_gen制作三组对应功能的中英文位图：keyword-discovery（关键词及国内海外多平台检索）、precision-analysis（行业与字段精度筛选）、lead-profiles（客户画像、线索分类和记录）。它们是AI生成的功能场景示意，不是已上线截图或真实采集结果；页面在图注和体验说明中明确标注。没有虚构采集成功率、客户证言或真实业绩。

三组中英文素材含1536/900像素响应式版本，共十二个WebP，合计1032758字节（约0.985MiB），全部随项目部署。首图优先加载，其余懒加载，保持3:2完整画面。`public/media/ai-leads/ASSETS.md`记录最终生成提示词和原始文件路径，`assets.json`记录尺寸、字节数与SHA256。无需外链素材或临时文件。

首屏轮播默认每6秒自动切换；支持上一张/下一张、指示点和播放/暂停。手动选择后暂停自动播放，悬停、焦点进入、后台标签页及系统减少动态效果时暂停，卸载清除定时器。中英文标题、说明、替代文本和图内界面文字均对应。2026-11-16新增三张简体中文版，中文页面使用-zh素材，英文页面保留原英文素材；轮播、下方介绍配图与响应式srcSet一起切换，不重置当前轮播位置。国际平台品牌名保留官方写法。

样式独立限定在`al-landing`，桌面首屏为右上角全局扫码入口留出空间；移动端改为单列。工作台原有功能和共用账户不变。

## 工作台

- 关键词输入、10/20/50/100/200条的数量选择。
- 平台按全部、国内、海外筛选；包含抖音、TikTok、Facebook、YouTube、WhatsApp、阿里巴巴国际站、淘宝、京东、1688、BOSS直聘、LinkedIn与企业官网/代理商。
- 营销内容提供眼科设备、电动车、工业机械、代理商/经销商预设和自定义补充。
- 展示字段支持头像、账号名称、账号ID、手机号、主页介绍、邮箱，默认选中前两项。
- “预览获客方案”检查关键词、平台和字段是否为空，并按条件展示最多3条明确标注的结构示例；所选采集数量是计划参数，不代表已采集数量。
- 可切换线索管理、调整示例分类、打开客户画像、查看和恢复本次预览条件。仅保留当前组件会话最近20次预览，刷新清除，不写浏览器存储或业务数据库。
- 邮箱使用示例域名，手机号标为待接入；不会生成或展示假冒真实客户的联系方式。

## 目录接入与范围

AI获客作为内置免费预览项同时出现在后台工具列表和前台目录，id为0，没有收费商品、付费权益或采集任务。后台支持查看宣传页、统一排序以及显示/隐藏工具目录卡片；隐藏目录不影响顶部AI导航和直接访问宣传页。预览行不提供积分/收款配置，商品保存接口也拒绝将该标识重复保存为收费产品。

排序与显示状态复用现有`tool_entry_settings`，前台在排序过滤之前加入AI预览项，确保后台设置同步生效。已有同标识旧商品不会生成重复入口或让预览继承收费。无需新增SQL；若服务器尚未执行既有15号工具管理SQL，后台仍展示该行并提示初始化，排序与隐藏按钮暂不可用。

`getPublishedTool('ai-leads')`和访问接口继续直接返回免费宣传入口，共用导航不依赖商品或积分配置。目录卡片标为“界面预览”。后续真实功能再设计商品、收费、权限、采集任务与表结构。

工作区原有未提交的 `lib/ai-leads.ts`、`lib/ai-leads-collector.ts` 草稿未接入这些页面，本轮不提交或运行它们。UI参数独立保存在 `lib/ai-leads-design.ts`，避免误触发草稿里的网络采集。

## 线上升级版本核对（2026-11-16）

本轮只读检查发现：两个线上域名的`/ai-leads`均返回200，语言为zh-CN，但五处配图src仍为旧英文文件；`/media/ai-leads/keyword-discovery-zh.webp`返回404。HTML响应为no-store。这表明线上正在运行的构建/静态资源尚未包含3c9cfe8的中文版改动，不能仅凭“执行过升级”认定已部署同一版本。

`upgrade.sh`逻辑保持原样：读取当前分支的上游分支（未设置时为origin/当前分支），git fetch后同步该远程分支，再构建并启动。只在Windows提交或合并本地main，不会自动更新Linux使用的远程分支。先确认最新提交已推送到Linux跟踪的远程分支，再执行`bash upgrade.sh`。

Linux只读核对：

```bash
git log -1 --oneline
git branch --show-current
git rev-parse --abbrev-ref --symbolic-full-name '@{upstream}'
ls public/media/ai-leads/*-zh.webp
```

已向用户询问Linux当前提交和上游分支；本轮不远程登录、不操作线上数据库、不推送或重启线上服务。
