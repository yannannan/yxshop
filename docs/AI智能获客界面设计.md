# AI智能获客界面预览

2026-11-15。本轮只落地页面与演示交互，不接入真实采集、模型、客户数据或积分扣费。

## 访问入口

- 顶部“AI智能获客”和工具目录新增卡片都进入 `/ai-leads`。
- 宣传页的“开始我的获客”进入 `/ai-leads/workspace`。
- `/tools/ai-leads.html` 永久重定向到同一个宣传页。
- 两个页面共用商城的 StorefrontHeader、语言与账户组件，账号、管理员入口和积分信息沿用现有功能。全局手机访问二维码也继续展示。

## 当前宣传页（纵向功能叙事版）

按用户最新要求，移除宣传页内部额外的产品导航，只保留商城共用顶部导航。页面使用雾白、冰蓝与品牌蓝，按以下顺序纵向展示：

1. 首屏说明AI获客目标，明确“开始我的获客”入口，展示三张功能场景轮播。
2. 目标市场与平台：国内、海外与代理商场景；按全部/国内/海外筛选规划中的平台。
3. 关键词与数据精度：产品/行业词、营销内容、每次数量与信息字段。
4. 客户画像与线索管理：客户背景、分类状态、检索和跟进记录。
5. 四步使用路径、简短体验说明与末屏开始入口。

原先办公室、港口、城市等泛化摄影已从页面及发布素材中移除。使用内置image_gen制作三张对应功能的位图：keyword-discovery（关键词及国内海外多平台检索）、precision-analysis（行业与字段精度筛选）、lead-profiles（客户画像、线索分类和记录）。它们是AI生成的功能场景示意，不是已上线截图或真实采集结果；页面在图注和体验说明中明确标注。没有虚构采集成功率、客户证言或真实业绩。

三组素材含1536/900像素响应式版本，共六个WebP，合计520650字节（约508KiB），全部随项目部署。首图优先加载，其余懒加载，保持3:2完整画面。`public/media/ai-leads/ASSETS.md`记录最终生成提示词和原始文件路径，`assets.json`记录尺寸、字节数与SHA256。无需外链素材或临时文件。

首屏轮播默认每6秒自动切换；支持上一张/下一张、指示点和播放/暂停。手动选择后暂停自动播放，悬停、焦点进入、后台标签页及系统减少动态效果时暂停，卸载清除定时器。中英文标题、说明和替代文本均对应；位图内英文作为概念画面的一部分，不冒充工作台的实际界面语言。

样式独立限定在`al-landing`，桌面首屏为右上角全局扫码入口留出空间；移动端改为单列。工作台原有功能和共用账户不变。

## 工作台

- 关键词输入、10/20/50/100/200条的数量选择。
- 平台按全部、国内、海外筛选；包含抖音、TikTok、Facebook、YouTube、WhatsApp、阿里巴巴国际站、淘宝、京东、1688、BOSS直聘、LinkedIn与企业官网/代理商。
- 营销内容提供眼科设备、电动车、工业机械、代理商/经销商预设和自定义补充。
- 展示字段支持头像、账号名称、账号ID、手机号、主页介绍、邮箱，默认选中前两项。
- “预览获客方案”检查关键词、平台和字段是否为空，并按条件展示最多3条明确标注的结构示例；所选采集数量是计划参数，不代表已采集数量。
- 可切换线索管理、调整示例分类、打开客户画像、查看和恢复本次预览条件。仅保留当前组件会话最近20次预览，刷新清除，不写浏览器存储或业务数据库。
- 邮箱使用示例域名，手机号标为待接入；不会生成或展示假冒真实客户的联系方式。

## 目录接入与范围

本轮不需要SQL：AI获客作为内置界面预览入口附加在现有配置工具之后，保留原排序、上下架与分页；如果已有同标识产品，则不重复插入。预览对象的id为0，表示没有对应收费商品，不用于订单、积分、套餐、业务采集或持久任务。

`getPublishedTool('ai-leads')`和访问接口可直接返回预览入口，导航不会等待采集服务。目录卡片标为“界面预览”。这不是一个已在管理端注册的可收费工具；后续做真实功能时，再确定商品、模块收费、权限、任务和表结构。

工作区原有未提交的 `lib/ai-leads.ts`、`lib/ai-leads-collector.ts` 草稿未接入这些页面，本轮不提交或运行它们。UI参数独立保存在 `lib/ai-leads-design.ts`，避免误触发草稿里的网络采集。

## 站长工具入口修正

整合工作区已有的旧标识/名称兼容修正，统一 `isWebsiteAnalysis` 与分析服务识别：`yxstar-site-tool`、既有六个标识以及“站长分析工具/站长运营工具”均可进入原工作区，不改域名、站点归属、历史记录或收费。

访问接口增加读取数据库里的工具名称；按名称识别的旧工具也使用本站工作区入口，避免仍要求配置外部URL。工具卡片同步复用站长图标。旧地址仍可用，不需要改产品记录。
