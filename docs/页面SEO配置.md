# 页面标题、关键词与描述

2026-11-19更新。用户要求为每个页面分别定义搜索引擎信息，并在所有页面加入：**宇星脉通、AI智能获客、AI贸易获客、AI外贸获客**。

## 实现与维护

- `lib/page-seo.ts`集中维护各页中英文标题、描述和关键词。各页先说明自己的功能，再自动补齐四个固定中文词。四词同时出现在`meta keywords`、`meta description`、Open Graph与Twitter描述中，英文页面同样保留原中文词；关键词去重。
- `lib/page-seo-server.ts`按请求读取语言。公开目录、个人中心子页与客户端页面的服务端布局均已接入；根布局提供首页信息。页面不增加可见关键词条，不改变界面、菜单、收费或权限。
- 公开页面拥有各自canonical，商品与服务详情使用具体地址；账户/订单/管理端等非公开内容不继承首页canonical，并维持或补齐`noindex`。
- `next.config.ts`使用框架支持的`htmlLimitedBots: /.*/`，使携带User-Agent的浏览器与爬虫等待SEO生成，将标签放入初始HTML的`head`，避免依赖客户端脚本搬移流式标签。商品/服务详情因此会在返回首份页面前读取对应公开资料；不进行数据库初始化或写入。

## 后台自定义与真实资料

工具管理现有的SEO标题、SEO描述继续优先使用；保存自定义描述后，渲染时自动补齐缺少的固定词，无需修改旧数据。未填写时按工具功能选用默认文案。AI获客始终描述当前预览状态，不宣称已开放真实采集。

商品详情原先从代码种子商品生成SEO，已改为读取实际已上架商品；积分商品、已下架和不存在的商品不输出可收录详情。技术服务只读取有效服务与有效技术人员的公开摘要，旧库确实缺少服务表时才复用原公开服务兼容资料。连接失败不会退回已过时的商品种子或泄露数据库错误。

## 搜索引擎说明与来源

关键词标签按用户要求保留。Google明确说明它不使用`meta keywords`决定收录或排名；本次同时完善各页独立描述、标题及服务端标签。[Google支持的meta标签](https://developers.google.com/search/docs/crawling-indexing/special-tags)

描述应准确总结对应页面，并避免所有页面使用完全相同内容；搜索引擎可能选择正文而非设定描述作为搜索摘要。[Google描述与摘要说明](https://developers.google.com/search/docs/appearance/snippet)

初始HTML头部输出采用框架正式配置，不修改依赖包。[Next.js htmlLimitedBots](https://nextjs.org/docs/app/api-reference/config/next-config-js/htmlLimitedBots)
