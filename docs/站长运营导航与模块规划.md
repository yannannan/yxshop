## 导航

| 一级入口 | 二级入口 |
| --- | --- |
| 站点管理 | 无，原各站域名 / 永久脚本 / 验证 / 删除仍在同一卡片 |

共19个页面入口，左侧最多两层。SEO页面内用搜索表现 / 关键词与排名 / 页面收录标签；页面分析用访问 / 内容 / 行为标签；健康页面用健康检查 / 页面响应 / 网站性能标签。标签支持左右方向键、Home和End。

原TXT的01归综合看板，02、03、07、10归访问分析；04、05、06归SEO；08、09归转化营收；11、12归健康性能；13爬虫、15外链、20竞品分别归对应页面。14内容、16AI SEO、17预警、18报表归运营工具；19保留在站点管理。AI获客作为独立扩展。

## 数据与交互

- 统计接口在原归属校验后读取既有访问表，增加按路径聚合（最多100个已访问路径）、按北京时间日期聚合、近5分钟活跃会话。查询不创建分析任务或扣费。
- 路径区分大小写，查询参数 / 片段继续不入库。Title匹配当前采集报告中的同路径页面，未采集则显示未读取。报告页面未出现在100个访问路径时，不虚构零PV。
- 会话不等于独立访客UV；地区未接入显示未识别。日趋势只列有上报的日期；读取失败、未接入和缺失指标有独立状态。
- URL保留view / site / run，刷新与浏览器前后退恢复页面，原仅带run的链接继续进入看板。查看模块只读已有结果，所选站点和切换账号的数据不会混入其他站点 / 账号。
- 新分析仍需已验证站点。实时刷新在离开模块、切换站点 / 账号或卸载时取消。站点选择和页面浏览不会自动分析或扣费。
- 前台同步中英文，原管理端保持中文。新增菜单在lib/site-workspace.ts登记，并落实模块页面、数据权限和英文词典。
